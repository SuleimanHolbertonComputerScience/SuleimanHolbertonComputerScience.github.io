## 🚀 Architectural SEO & Performance Specifications

This web platform is engineered with **Principal/Architect-grade Search Engine Optimization (SEO)**:

* **Structured Data (Schema.org / JSON-LD):**
  * `EducationalOrganization` Schema with founder, logo, sameAs, and contact attributes.
  * `Person` Schema for author leadership.
  * `WebSite` & `WebPage` with hierarchical `BreadcrumbList`.
  * `FAQPage` Schema generating rich interactive accordion snippets on Google SERP.
  * `Course` & `ItemList` Schemas covering all 9 primary curriculum tracks.
* **Crawler Indexing Directives:**
  * Strict canonical URL enforcement (`https://suleimanholbertoncomputerscience.github.io/`).
  * Dedicated `robots.txt` granting explicit allow directives to Googlebot, Bingbot, YandexBot, DuckDuckBot, Applebot, and Baiduspider.
  * Comprehensive `sitemap.xml` indexing 22 canonical paths and deep anchor sitelinks.
* **Social Graph & Media Optimization:**
  * OpenGraph (Facebook, LinkedIn, Discord, Telegram, WhatsApp) with secure 1024x1024 preview image metadata.
  * Twitter Cards (X Platform) with `summary_large_image` support.
* **Mobile & Technical SEO:**
  * Progressive Web App `manifest.json` metadata for mobile search indexing.
  * Accessibility-first markup: screen reader skip links, semantic landmarks (`main`, `nav`, `section`, `article`, `header`, `footer`), and explicit image dimensions to eliminate Cumulative Layout Shift (CLS).
  * High-priority hero image loading (`fetchpriority="high"`, `loading="eager"`).

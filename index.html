🗂️ Curriculum Modules

Comprehensive architectural breakdown of all coursework modules completed during the intensive Holberton School program (maintained in the private vault)

⚙️

Low-Level Programming & C

Direct virtual memory layout, 64-bit pointer arithmetic, dynamic heap allocations (malloc/free), structures, bitwise masking, and hardware-level execution.

C · Valgrind
🖨️

Custom printf Engine

From-scratch implementation of the standard C printf with 1024-byte user-space buffering, variadic argument handling (va_list), and specifier dispatch tables.

C · System Calls
🌲

Binary Trees & AVL Balancing

Binary Search Trees (BST), AVL self-balancing rotations (LL, RR, LR, RL), Binary Heaps, and mathematical proof of logarithmic height bounds.

C · Algorithms
⚡

Sorting Algorithms & Complexity

Bubble, Insertion, Quick (Lomuto), Merge, and Heap sorts. Proof of the $\Omega(N \log N)$ comparison sort lower bound and linear Counting Sort.

C · Big-O Analysis
💲

UNIX Simple Shell Interpreter

POSIX command-line interpreter: process forking (fork), execution (execve), Copy-on-Write (COW), signal trapping, and PATH resolution.

C · POSIX · Linux
🐍

Higher-Level Python & ORM

Python dynamic internals ("everything is an object"), Object-Oriented Programming (OOP), Test-Driven Development (TDD), and SQLAlchemy ORM mapping.

Python · SQL · SQLAlchemy
🏠

AirBnB Clone (hbnb) Suite

Multi-phase MVC application: interactive CLI console, JSON file serialization, MySQL relational database engine, Flask web routing, and RESTful API.

Python · Flask · MySQL
🐳

DevOps, Docker & Systems

Linux server administration, idempotent Bash automation, Nginx reverse proxy load balancing, SSL/TLS certificates, and Docker containerization.

Bash · Docker · Nginx
🌐

Network Protocols & Sockets

OSI 7 layers, TCP 3-way handshakes, UDP datagrams, Berkeley sockets API, DNS resolution chain, and HTTP/HTTPS request-response lifecycles.

Networking · POSIX Sockets
⚛️

Web Front-End: Modern React

Declarative UI architecture: Virtual DOM reconciliation, React Hooks (useState, useEffect, useMemo), and compile-time TypeScript type safety.

React · TypeScript
🚀

Web Back-End: Node.js & MongoDB

Non-blocking asynchronous I/O with the libuv event loop, Express REST API middleware chaining, cursor pagination, and NoSQL MongoDB storage.

Node.js · Express · MongoDB
🛠️

Fix My Code Polyglot Debugging

Systematic root cause analysis: off-by-one errors, memory corruption, and logical flaws across C, Python, JavaScript, and Ruby codebases.

GDB · Valgrind · RCA

🔬 CS Foundations → Bioinformatics Bridge

How each computer science domain directly powers high-throughput bioinformatics, phylogenetics, and computational genomics

🧠

C Memory Management → Sequence Parsers

Direct pointer manipulation, memory-mapped files (mmap), and 2-bit nucleotide bitpacking are required to engineer ultra-fast genomic aligners like BLAST, BWA, and Bowtie.

🌳

Tree & Graph Algorithms → Phylogenetics & Assembly

Post-order traversals power Felsenstein’s likelihood pruning algorithm for evolutionary trees; Eulerian paths over de Bruijn graphs solve de novo genome assembly.

🐳

Docker & DevOps → Reproducible Workflows

Containerizing software stacks into OCI images guarantees 100% scientific reproducibility across Nextflow, Snakemake, and HPC SLURM cluster pipelines.

🐍

Python OOP → Biopython Omics Tooling

Object-oriented abstractions allow structured handling of biological entities: SeqRecord features and macromolecular Structure-Model-Chain-Residue-Atom (SMCRA) hierarchies.

🔌

REST APIs & Sockets → Global Biological Databases

Persistent TCP connection pooling and exponential backoff enable high-throughput programmatic data retrieval from NCBI, Ensembl, UniProt, and AlphaFold DB.

🖥️

System Engineering → HPC Clusters

Linux sysadmin, process management, and POSIX shell scripting are crucial for managing cluster job arrays and multi-terabyte sequencing pipelines.

❓ Frequently Asked Questions (FAQ)

Clear answers regarding organization architecture, coursework access, and scientific alignment

What is SuleimanHolbertonComputerScience?
SuleimanHolbertonComputerScience is the official organizational knowledge hub archiving coursework, projects, and systems architectures completed during the 9-month intensive Computer Science and Software Engineering program at Holberton School by Suleiman Hajizadeh. It uniquely demonstrates how bare-metal systems programming directly underpins modern computational biology.
Why are the core source code and repositories private?
The core repository (featuring 1,832+ git commits across 16 curriculum modules) and the internal 38+ page Obsidian LLM Wiki are maintained as Private to preserve academic integrity, prevent plagiarism of Holberton School curriculum solutions, and protect proprietary research architectures.
How can recruiters, evaluators, or researchers request access?
Read access is granted upon request. Recruiters, academic reviewers, and collaborators can request access by sending an email to suleyman.hacizade1@gmail.com. Please state your name, organization, and the purpose of your review.
How do Computer Science foundations apply to Bioinformatics?
Bioinformatics tools must handle massive genomic datasets. Low-level C memory management powers sequence aligners (like BLAST, BWA, Bowtie); binary trees and graph traversals solve phylogenetic inference and genome assembly; and Docker/DevOps ensures reproducible pipelines in Nextflow and Snakemake on HPC supercomputers.
What is the Obsidian LLM Wiki inside this repository?
The repository contains a persistent, compounding Obsidian LLM Wiki (38+ markdown notes) governed by AGENTS.md. It indexes all curriculum modules, fundamental CS concepts, Big-O complexity cheat sheets, and explicit bioinformatics bridge syntheses interconnected via bidirectional [[wikilinks]].
